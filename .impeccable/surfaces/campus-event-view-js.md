# Campus board extension
Mode: Operate. Add a local board below the existing exploration map, using current forest-green ink, pale paper, serif headings, simple rule-separated rows and existing controls. No new visual world.
## Direction contract
THESIS: A campus notice becomes a real shared activity with NPC schedules, memories and measurable growth, rather than a decorative event list.
OWN-WORLD: Preserve incumbent map, typography and paper palette; reuse student imagery. Rows with time, place and specific action.
STORY: Browse three upcoming rotating activities, reserve free time, go to the location, attend once and revisit the people met.
FIRST VIEWPORT: Preserve the map viewport; the board follows the map and carries dates, titles, venues, rewards and reservation/attendance state. Mobile stacks actions underneath content without horizontal scrolling.
FORM: Precisely scoped extension of exploration/planner, code-led; seed inapplicable. Signature interaction is turning a listed event into a personal reminder and actual shared memory with present students.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
Constraints: free recurring activities, real attendance, no forced romance, no stat farming, respect existing NPC appointments; new character rasters carry embedded prompts. Optional future work is recorded separately from delivered features.
