Campus Go v0.17 靜態網站包
1. 這是可供靜態網站平台託管的完整網頁根目錄，首頁是 index.html。
2. 公開發布需先連接 Render 或其他託管服務，請勿把 Google Drive ZIP 誤認成網站。
3. Render 可建立 Static Site，發佈目錄設為根目錄「.」，建置命令可留空或 echo ready。
4. 現有程式源自 v0.5 演進的 v0.16，包含七位學生圖片；v0.6 的完整原始碼目前無法核對。
5. 目前無雲端存檔或真正的角色語言模型；畫面本機規則模擬。
6. 本包不含未使用的原始高解析人物參考圖，以減少意外公開原圖。S047 的遊戲參考縮圖仍會公開；發布前請檢查照片公開權利。
7. 若需離線單檔遊玩，請改用 CampusGo_v017_Offline_Play.html。
